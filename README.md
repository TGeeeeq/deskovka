# Než přijde zima

Kooperativní desková hra ze skutečné Louky azylu **Nech mě růst z.s.** ve Vlkanči.
Šest zvířat — Karel, Pogo, Avala, Květa, Flíček a Yakul — chystá seno, pelíšky a bylinky na zimu.
Protivníkem je jen počasí. 1–4 hráči, 8–100+ let, 30–45 minut.

- **Hra v prohlížeči:** `/` — hot-seat pro 1–4 hráče, boti na doplnění, Karlův průvodce.
- **Prezentace:** `/prezentace/` — pro dárce, partnery a sbírku na vydání.
- **Tisk:** `/tisk/` a `npm run print` — PnP karty, deska, žetony, pravidla A5.
- **3D figurky:** `npm run models` — STL figurek, podstavců a žetonů.
